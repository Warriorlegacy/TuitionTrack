Introduction: Real-world Applications, Why Polynomials Matter, and the Concept of Variable

• Polynomials model real-world curves like roller coasters and bridges.
• Used in physics to track motion and in economics to model trends.
• Variable: A symbol like x or y representing a changing value.
• Constant: A fixed value that does not change, such as 5 or -10.
• Algebra uses variables to create general rules instead of specific sums.

Algebraic Expressions vs. Polynomials: Definitions, Terms, Coefficients, and Degree

• Algebraic Expression: Any combination of variables and constants.
• Polynomial Rule: Variable exponents must be whole numbers (0, 1, 2...).
• Terms: Parts of an expression separated by + or - signs.
• Coefficient: The numerical factor multiplying a variable.
• Degree: The highest exponent of the variable in the polynomial.

Types of Polynomials: Based on Number of Terms and Degree

• Classification by Terms: Monomial (1), Binomial (2), Trinomial (3)
• Classification by Degree: The highest power of the variable
• Degree 0: Constant Polynomial; Degree 1: Linear Polynomial
• Degree 2: Quadratic Polynomial; Degree 3: Cubic Polynomial
• Example: 3x squared minus 5x plus 2 is a Quadratic Trinomial

Zeroes of a Polynomial: Concept, Finding Zeroes of Linear Polynomials, and Graphical Interpretation

• A zero is a value that makes the polynomial equal to zero.
• For p(x), 'a' is a zero if p(a) = 0.
• To find the zero of a linear polynomial, solve a(x) + b = 0.
• Every linear polynomial has exactly one unique zero.
• Graphically, the zero is the point where the graph intersects the x-axis.

Remainder Theorem: Concept, Formal Statement, and Step-by-Step Numerical Derivation

• Remainder Theorem: Find the remainder without long division.
• Formal Statement: If P(x) is divided by (x - a), the remainder is P(a).
• The Division Algorithm: P(x) = (x - a)Q(x) + R.
• Step 1: Find the zero of the divisor (set divisor to zero).
• Step 2: Substitute that value into the polynomial to get the remainder.

Factor Theorem: Relationship between Zeroes and Factors, and Testing Divisibility

• Remainder Theorem Recap: Remainder is p(a) when dividing by (x - a)
• Factor Theorem: (x - a) is a factor if and only if p(a) = 0
• The Two-Way Relationship: Zeroes imply factors, and factors imply zeroes
• Testing Divisibility: If p(a) = 0, the polynomial is divisible by (x - a)
• Pro-Tip: Always flip the sign of the constant in the divisor when testing

Factorization Part 1: Splitting the Middle Term for Quadratic Polynomials

• Standard Form: ax^2 + bx + c
• Condition 1: Sum of terms (p + q) must equal b
• Condition 2: Product of terms (p * q) must equal a * c
• Step 1: Rewrite the middle term using p and q
• Step 2: Factor by grouping common terms

Factorization Part 2: Factor Theorem Method for Cubic Polynomials and Long Division

• Cubic polynomials require a multi-step factorization approach.
• Use the Factor Theorem to find the first zero by testing factors of the constant.
• If p(a) = 0, then (x - a) is a factor of the polynomial.
• Perform Long Division to divide the cubic by the linear factor.
• Factorize the resulting quadratic quotient using splitting the middle term.

Algebraic Identities Part 1: Square Identities

• Identity 1: (a + b)² = a² + 2ab + b²
• Identity 2: (a - b)² = a² - 2ab + b²
• Identity 3: a² - b² = (a + b)(a - b)
• Identities are true for all values of the variables
• Use identities to simplify mental math and factorization

Algebraic Identities Part 2: Cubic Identities

• Identity 1: (a + b)³ = a³ + 3a²b + 3ab² + b³
• Identity 2: (a - b)³ = a³ - 3a²b + 3ab² - b³
• Identity 3: a³ + b³ + c³ - 3abc = (a + b + c)(a² + b² + c² - ab - bc - ca)
• Special Case: If a + b + c = 0, then a³ + b³ + c³ = 3abc
• Watch the signs carefully when expanding (a - b)³
