Foundations: Concept of One-to-One/Onto Functions & The Need for Inverses

• Function: A mapping from Domain to Co-domain
• One-to-One (Injective): Distinct inputs must have distinct outputs
• Onto (Surjective): Range must equal the Co-domain
• Bijective: A function that is both One-to-One and Onto
• The Problem: Periodic trig functions are Many-to-One and need restriction

Defining Inverse Trigonometric Functions: Domain and Range (Principal Value Branches)

• Trigonometric functions are periodic and many-to-one by nature.
• To define an inverse, we must restrict the domain to make it bijective.
• The restricted range of the inverse is called the Principal Value Branch.
• Sine and Cosine use different intervals to ensure one-to-one mapping.
• Domain and Range swap roles when moving from a function to its inverse.

The Principal Value Branch Table: Mastery of Domains and Ranges

• Sin inverse and Tan inverse: Range is (-pi/2, pi/2)
• Cos inverse and Cot inverse: Range is [0, pi]
• Cosec inverse and Sec inverse: Mirror ranges of Sin and Cos
• Domain of Sin/Cos: [-1, 1]; Domain of Tan/Cot/Sec/Cosec: Real numbers/Restricted
• Always check if your final angle lies within the Principal Value Branch

Properties of Inverse Functions: Composition and Identity Relationships

• Composition: f(f inverse(x)) = x if x is in the domain
• Composition: f inverse(f(theta)) = theta if theta is in the principal range
• Sine and Cosine identities require x to be between -1 and 1
• Tangent identity is valid for all real numbers x
• Always check if the angle falls within the Principal Value Branch

Advanced Properties: Sum and Difference Formulas for Arctan/Arcsec/Arccsc

• Arctan(x) + Arctan(y) = Arctan((x + y) / (1 - xy)) for xy < 1
• Arctan(x) - Arctan(y) = Arctan((x - y) / (1 + xy)) for xy > -1
• Always check the product xy to ensure the result stays in the Principal Value Branch
• Convert Arcsec(x) to Arccos(1/x) and Arccsc(x) to Arcsin(1/x) for easier calculation
• Use reciprocal identities to apply standard sum/difference rules to all inverse functions
