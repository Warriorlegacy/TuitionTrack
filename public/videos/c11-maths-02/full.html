Cartesian Product of Sets: Definitions, Operations, and Visualizing Ordered Pairs

• Definition: A cross B is the set of all ordered pairs (a, b) where a is in A and b is in B
• Ordered Pairs: The sequence (a, b) is distinct from (b, a) unless a equals b
• Cardinality Rule: If A has m elements and B has n elements, A cross B has m times n elements
• Empty Set Property: If either set is empty, the Cartesian product is also an empty set
• Visualization: Ordered pairs can be plotted as points on a 2D Cartesian coordinate grid

Relation: Definition, Domain, Codomain, and Range with Worked Examples

• Relation: A subset of the Cartesian product A x B
• Domain: The set of all first elements in the ordered pairs
• Codomain: The entire set B from which second elements are drawn
• Range: The set of all second elements actually used in the relation
• Key Rule: The Range is always a subset of the Codomain

Types of Relations: Reflexive, Symmetric, Transitive, and Equivalence Relations

• Reflexive: Every element 'a' is related to itself (a, a) ∈ R
• Symmetric: If (a, b) ∈ R, then (b, a) must also be in R
• Transitive: If (a, b) ∈ R and (b, c) ∈ R, then (a, c) must be in R
• Equivalence Relation: A relation that is Reflexive, Symmetric, and Transitive
• Example: The 'equal to' relation is a perfect Equivalence Relation

Introduction to Functions: Mapping, Domain, Codomain, and Range Concepts

• A function is a special relation where every input has exactly one output.
• Domain: The set of all first elements (inputs) in the relation.
• Codomain: The entire set of potential output values.
• Range: The set of actual values produced by the function (subset of Codomain).
• Rule: Every element in the domain must be mapped, and only to one element.

Types of Functions I: Identity, Constant, Polynomial, Rational, and Modulus Functions

• Constant Function: f(x) = c (Horizontal line)
• Identity Function: f(x) = x (Diagonal line through origin)
• Polynomial Function: f(x) = a_n x^n + ... + a_0
• Rational Function: f(x) = p(x) / q(x), where q(x) is not zero
• Modulus Function: f(x) = |x| (V-shaped graph)

Part 7 of 12 · ~4 min

Types of Functions II: Signum, Greatest Integer Function, and Exponential Functions

• Signum Function: f(x) = 1 if x > 0, 0 if x = 0, and -1 if x < 0
• Greatest Integer Function: Output is the largest integer <= x
• Signum and Greatest Integer functions are known as Step Functions
• Exponential Function: f(x) = a to the power of x, where a > 0 and a is not 1
• Exponential functions have a domain of all real numbers and range of positive reals

Algebra of Real Functions: Addition, Subtraction, Multiplication, and Division of Functions

• Addition: (f + g)(x) = f(x) + g(x)
• Subtraction: (f - g)(x) = f(x) - g(x)
• Multiplication: (fg)(x) = f(x) * g(x)
• Division: (f/g)(x) = f(x) / g(x), where g(x) is not zero
• Domain of combined functions is the intersection of individual domains

Common Pitfalls: Identifying Non-functions, Mapping Errors, and Notation Mistakes

• Vertical Line Test: A function must pass this to avoid multiple y-values for one x.
• Codomain vs. Range: Range is the set of actual outputs; Codomain is the target set.
• Domain Restrictions: Always check for zero denominators and negative square roots.
• Correct Substitution: Use f of x notation properly when solving equations.
• Interval Notation: Distinguish carefully between inclusive square and exclusive parentheses.
