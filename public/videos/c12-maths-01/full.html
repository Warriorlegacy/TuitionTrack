Relations: Cartesian Products, Definition, Domain, Codomain, and Range

• Cartesian Product A x B: Set of all ordered pairs (a, b) where a is in A and b is in B
• Number of elements in A x B = (number of elements in A) times (number of elements in B)
• Relation: A subset of the Cartesian Product that satisfies a specific rule
• Domain: The set of all first elements in the ordered pairs of a relation
• Codomain: The entire set B; Range: The set of all second elements actually used

Part 3 of 12 · ~5 min

Types of Relations: Reflexive, Symmetric, Transitive, and Equivalence Relations

• Reflexive: Every element 'a' must be related to itself as (a, a).
• Symmetric: If (a, b) is in R, then (b, a) must also be in R.
• Transitive: If (a, b) and (b, c) are in R, then (a, c) must be in R.
• Equivalence Relation: A relation that is Reflexive, Symmetric, and Transitive.
• Common Pitfall: Transitivity requires a chain; without a chain, it's vacuously true.

Equivalence Classes: Deep Dive, Properties, and Partitioning Sets

• Equivalence Class [a]: The set of all elements related to 'a' in set A.
• Reflexivity ensures that every element 'a' belongs to its own class [a].
• Two equivalence classes are either identical or completely disjoint.
• Partitioning: Equivalence classes divide a set into non-overlapping subsets.
• The union of all distinct equivalence classes equals the original set A.

Functions: Definition, Mapping Types, and Domain-Range Analysis

• Function: A relation where every element in A has exactly one image in B.
• Domain: The set of all possible input values.
• Codomain vs. Range: Range is the set of actual outputs; Codomain is the target set.
• Many-to-One: Multiple inputs can result in the same output.
• Domain Analysis: Finding values where the function is mathematically defined.

One-to-One (Injective) Functions: Algebraic Proofs and Graphical Tests

• Definition: Distinct inputs must yield distinct outputs.
• Algebraic Proof: Assume f(x1) = f(x2) and solve for x1 = x2.
• Counter-example: If x1 can equal -x2, the function is not injective.
• Horizontal Line Test: Graph must intersect any horizontal line at most once.
• Monotonicity: Strictly increasing or decreasing functions are always injective.

Part 7 of 12 · ~5 min

Onto (Surjective) Functions: Range vs Codomain and Formal Proofs

• Codomain: The entire target set B.
• Range: The set of actual outputs produced by the function.
• Onto (Surjective): A function where Range equals Codomain.
• Formal Proof Step 1: Let y be an arbitrary element in the Codomain.
• Formal Proof Step 2: Solve y = f(x) for x to find the pre-image.

Part 8 of 12 · ~5 min

Bijective Functions: The Intersection of Injective and Surjective Properties

• Definition: A function is bijective if it is both Injective and Surjective.
• Bijective functions create a perfect one-to-one correspondence between sets.
• To prove Bijectivity: 1. Prove Injective (f(x1)=f(x2) implies x1=x2).
• To prove Bijectivity: 2. Prove Surjective (Range must equal Codomain).
• Bijectivity is the necessary and sufficient condition for an Inverse Function.

Composition of Functions: Operations, Notation, and Existence Conditions

• Definition: Combining two functions where the output of one is the input of another
• Notation: f circle g of x is written as f(g(x))
• Order Matters: Generally, f circle g is NOT equal to g circle f (Non-commutative)
• Existence Condition: Range of inner function must be a subset of Domain of outer function
• Inner vs Outer: In f circle g, g is the inner function applied first

Invertible Functions: Deriving Inverses and Necessary Conditions

• A function is invertible if and only if it is bijective (one-to-one and onto).
• The domain of f becomes the range of f inverse, and vice versa.
• Step 1: Set y equals f of x. Step 2: Solve the equation for x in terms of y.
• Step 3: Replace x with f inverse of y. Step 4: Replace y with x.
• Verification: f of f inverse of x must equal x.

Special Functions: Signum, Greatest Integer, Modulus, and Identity Functions

• Identity Function: f(x) = x; output is identical to input.
• Modulus Function: f(x) = |x|; always returns non-negative values.
• Signum Function: Returns 1 for positive, -1 for negative, and 0 for zero.
• Greatest Integer Function: Returns the largest integer less than or equal to x.
• Key Concept: These functions are essential for modeling step-like and magnitude behaviors.
