The Cartesian Plane: Coordinate Systems, Axes, and Quadrants

• Cartesian Plane: A 2D surface defined by two perpendicular axes.
• The Origin: The intersection point where x equals zero and y equals zero.
• Quadrants: Four regions numbered I, II, III, and IV counter-clockwise.
• Abscissa and Ordinate: x is the horizontal distance; y is the vertical distance.
• Axis Points: Points on the x-axis have y=0; points on the y-axis have x=0.

Distance Formula: Derivation, Concept, and Basic Calculations

• Distance is the straight-line length between two points
• Derivation is based on the Pythagoras Theorem
• Formula: Distance = square root of (x2-x1)^2 + (y2-y1)^2
• Squaring differences ensures distance is always positive
• Watch out for sign errors when subtracting negative coordinates

Section Formula: Internal Division and Ratio Concepts

• Point P divides segment AB in the ratio m1 : m2
• X-coordinate formula: (m1*x2 + m2*x1) / (m1 + m2)
• Y-coordinate formula: (m1*y2 + m2*y1) / (m1 + m2)
• The ratio m1 is paired with the coordinates of point B
• The ratio m2 is paired with the coordinates of point A

Section Formula Deep Dive: Finding Coordinates and Ratios

• Assume ratio as k:1 to simplify solving for unknown ratios
• x-coordinate: (m1*x2 + m2*x1) / (m1 + m2)
• y-coordinate: (m1*y2 + m2*y1) / (m1 + m2)
• If point is on x-axis, set y = 0; if on y-axis, set x = 0
• Always multiply m1 with the second point and m2 with the first

Midpoint Formula: Special Case Derivation and Applications

• Midpoint is a special case of Section Formula where ratio m1:m2 = 1:1
• Midpoint X-coordinate: (x1 + x2) / 2
• Midpoint Y-coordinate: (y1 + y2) / 2
• Midpoint is the arithmetic mean of the endpoint coordinates
• Application: Proving diagonals of a parallelogram bisect each other

Area of a Triangle: Concept, Formula, and Collinearity Test

• Vertices: A(x1, y1), B(x2, y2), and C(x3, y3)
• Area = 1/2 |x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|
• Area is always positive; use absolute value bars
• Collinearity Test: If Area = 0, points are on a straight line
• If Area is not 0, points form a triangle
