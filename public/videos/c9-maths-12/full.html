• Observation: A single value in a data set.
• Frequency: The number of times a value repeats.
• Tally Marks: Using vertical lines and diagonal bundles of five.
• Organizing Data: Using columns for Observations, Tallies, and Frequency.

Grouped Frequency Distribution: Class Intervals, Class Limits, and Class Width

• Grouped Frequency Distribution: Organizing large datasets into ranges.
• Class Interval: A specific range of values (e.g., 10 to 20).
• Lower Class Limit: The smallest value in an interval.
• Upper Class Limit: The largest value in an interval.
• Class Width: The difference between the upper and lower limits.

Graphical Representation I: Bar Graphs and their Construction

• Bar graphs represent categorical data using rectangular bars.
• The height of the bar is proportional to the frequency.
• X-axis represents categories; Y-axis represents frequency.
• Crucial Rule: All bars must have equal width and uniform gaps.
• Always choose a suitable scale for the Y-axis.

Graphical Representation II: Histograms for Grouped Data

• Histograms are used for continuous grouped frequency distributions.
• Unlike bar graphs, histograms have no gaps between the bars.
• X-axis represents class intervals; Y-axis represents frequency.
• Ensure class intervals are continuous using class boundaries.
• The area and height of the bars represent the data density.

Graphical Representation III: Frequency Polygons and Construction Techniques

• Frequency Polygon: A line graph representing frequency distribution.
• Class Mark Formula: (Upper Limit + Lower Limit) / 2
• Method 1: Connecting midpoints of the tops of histogram bars.
• Method 2: Plotting Class Marks against Frequencies directly.
• Closing the Polygon: Extend lines to the x-axis at zero frequency.

Measures of Central Tendency: Concept of Average and Arithmetic Mean (Direct Method)

• Central Tendency: A single value representing the center of a data set.
• Arithmetic Mean: The most common measure, often called the 'Average'.
• Mean of Ungrouped Data: Sum of observations divided by total number of observations.
• Class Mark: The mid-point of a class interval, calculated as (Lower Limit + Upper Limit) / 2.
• Direct Method Formula: Mean = Sum of (Frequency x Class Mark) / Sum of Frequencies.

Calculating Mean: Assumed Mean Method and Properties of Mean

• Assumed Mean Method: A shortcut for large data sets
• Formula: Mean = A + (1/N) * Sum of (f sub i * d sub i)
• Deviation (d sub i) = x sub i - A
• Property 1: Sum of deviations from the mean is always zero
• Property 2: Changes in data scale the mean proportionally

Understanding Data Spread: Introduction to Range and Data Visualization

• Mean tells us the center; Spread tells us the variation.
• Range = Maximum Value minus Minimum Value.
• A small range indicates data is closely clustered.
• A large range indicates data is widely dispersed.
• Data Visualization helps identify patterns and shapes in data.

Common Mistakes in Statistics: Calculation Errors, Interval Misinterpretation, and Graphing

• Always double-check sums in Mean calculations to avoid arithmetic errors.
• In Assumed Mean Method, never forget to add the assumed mean 'A' at the end.
• Convert discontinuous intervals into continuous ones before drawing Histograms.
• Use a 'Kink' or zig-zag line if the X-axis does not start from zero.
• Always label both axes and ensure the Frequency Polygon touches the X-axis.
